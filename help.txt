У тебя есть полный набор инструментов:

deploy.ps1 - для серьезного деплоя с проверками
fix-404.ps1 - для исправления проблем
check-build.ps1 - для диагностики

# 📚 Документация скриптов деплоя LIMINAL

## 🎯 Обзор
Коллекция PowerShell скриптов для автоматизации деплоя React-приложения LIMINAL на GitHub Pages.

---

## 📋 Список скриптов

### 1. `deploy.ps1` - Основной деплой скрипт
**Назначение:** Полнофункциональный деплой с проверками и безопасностью

**Возможности:**
- ✅ Философские проверки от "6 мушкетёров DevOps"
- ✅ Dry-run режим для тестирования
- ✅ Детальное логирование в файл
- ✅ Автоматический stash текущих изменений
- ✅ Возврат на исходную ветку после деплоя
- ✅ Проверка существования папки dist
- ✅ Создание 404.html автоматически

**Использование:**
```powershell
.\deploy.ps1
```

**Интерактивность:** Да (запрашивает подтверждение dry-run)

**Время выполнения:** 30-60 секунд

**Логи:** Создает файлы `deploy-log-YYYYMMDD-HHMMSS.txt`

---

### 2. `fix-404.ps1` - Исправление 404 ошибок
**Назначение:** Специализированный скрипт для решения проблем с доступностью сайта

**Возможности:**
- 🔧 Автоматическое изменение base path на относительные пути
- 📝 Создание файла `.nojekyll` для отключения Jekyll
- 🚀 Принудительная пересборка проекта
- 📊 Показ содержимого папки dist
- 💡 Рекомендации по альтернативным решениям

**Использование:**
```powershell
.\fix-404.ps1
```

**Когда применять:**
- Сайт показывает 404 ошибку
- Проблемы с загрузкой ресурсов
- После изменения структуры проекта

**Изменения в проекте:**
- Меняет `vite.config.ts`: `base: '/land_plf/'` → `base: './'`
- Добавляет `.nojekyll` в папку dist

---

### 3. `check-build.ps1` - Диагностика и мониторинг
**Назначение:** Проверка статуса деплоя и диагностика проблем

**Возможности:**
- 🔍 Проверка существования ветки gh-pages
- 📝 Анализ последних коммитов
- 📋 Список файлов в ветке деплоя
- 📊 Размеры файлов (особенно index.html)
- 🌐 Тестирование доступности сайта (HTTP запрос)
- ⏰ Расчет времени с последнего деплоя
- 💡 Умные рекомендации по устранению проблем

**Использование:**
```powershell
.\check-build.ps1
```

**Типичный вывод:**
```
✅ Ветка gh-pages существует
📄 index.html: 50459 байт
✅ Сайт отвечает! Код: 200
⏱️ 5.2 минут назад
```

**Когда применять:**
- После деплоя для проверки
- При проблемах с доступностью
- Для мониторинга статуса

## 🚨 Устранение проблем

### Проблема: "git command not found"
**Решение:** Установи Git и добавь в PATH

### Проблема: "npm command not found" 
**Решение:** Установи Node.js

### Проблема: "remote origin already exists"
**Решение:** Нормально, скрипт это обработает

### Проблема: Сайт показывает 404 (ОСНОВНЫЕ ПРИЧИНЫ!)

**Причина #1: Не настроена ветка gh-pages в GitHub Pages**
**Пошаговое решение:**
1. Иди в **Settings** репозитория на GitHub
2. В левом меню найди секцию **"Code and automation"**
3. Выбери **"Pages"**
4. В разделе **"Build and deployment"**:
   - **Source**: выбери `Deploy from a branch` (НЕ GitHub Actions!)
   - **Branch**: выбери `gh-pages`
   - **Folder**: выбери `/ (root)`
5. Нажми **Save**
6. Подожди 2-5 минут
7. Проверь сайт: https://safal207.github.io/land_plf

**Причина #2: GitHub Actions неправильно собирает проект**
**ВАЖНО:** GitHub Actions по умолчанию может неправильно собрать Vite проект!

**Симптомы:**
- Source стоит на "GitHub Actions"
- Сайт показывает 404 или пустую страницу
- В Actions видны успешные deploy, но сайт не работает

**Решение:**
1. Переключи Source на `Deploy from a branch`
2. Используй наши PowerShell скрипты вместо Actions
3. Наши скрипты собирают проект правильно с нужными настройками

**Альтернативные решения:**
1. Запусти `.\check-build.ps1` для диагностики
2. Если проблема - запусти `.\fix-404.ps1`
3. **НЕ используй** GitHub Actions для Vite проектов без специальной настройки

### Проблема: "Permission denied"
**Решение:** Убедись что есть права на push в репозиторий

### Проблема: GitHub Pages не активируется
**Причины и решения:**
- **Репозиторий приватный**: Сделай публичным или используй GitHub Pro
- **Ветка gh-pages пустая**: Запусти любой из деплой скриптов
- **Source стоит на GitHub Actions**: Переключи на "Deploy from a branch"
- **GitHub Actions неправильно собирает**: Используй наши PowerShell скрипты
- **Неправильные настройки**: Проверь путь Settings > Code and automation > Pages

### Проблема: "Почему не GitHub Actions?"
**Ответ:** GitHub Actions для Vite требует специальной настройки:
- Нужен правильный workflow файл
- Правильные настройки base path
- Корректная конфигурация для React
- Наши PowerShell скрипты уже все это учитывают

## 📞 Поддержка

**При проблемах проверь:**
1. **ГЛАВНОЕ**: Настройки GitHub Pages в Settings > Code and automation > Pages
   - Source: "Deploy from a branch" (НЕ GitHub Actions!)
   - Branch: "gh-pages"
   - Folder: "/ (root)"
2. **Если стоит GitHub Actions**: Переключи на "Deploy from a branch"
3. Работает ли `npm run build` локально
4. Есть ли доступ к GitHub (git push)
5. Существует ли ветка gh-pages: `git branch -r | grep gh-pages`

**Полезные команды для диагностики:**
```powershell
# Проверить git статус
git status

# Проверить remote
git remote -v

# Ручная сборка
npm run build
```
